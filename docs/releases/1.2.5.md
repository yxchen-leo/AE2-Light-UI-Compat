# v1.2.5

## Changes / 更新内容

- Connect AE2's 1.20.1 scrollbar renderer to the modern AE2 sprites already present in resource pack v1.2.4. Normal handles use `big_scroller`, and narrow handles use `small_scroller`, with separate enabled and disabled textures.
- Keep the existing 12×15 / 7×15 dimensions and all scrolling, drag, paging, and hitbox calculations. Rendering uses the correct standalone texture dimensions instead of the old 256×256 atlas UVs.
- Apply to AE2 and addons that reuse its DEFAULT or SMALL scrollbar styles. Leave addon-defined styles and unrelated Minecraft interfaces unchanged. Disabling the companion pack or removing a sprite restores the original rendering.

- 将 AE2 1.20.1 滚动条绘制接到资源包 v1.2.4 已有的高版本贴图：普通滑块使用 `big_scroller`，窄型使用 `small_scroller`，分别处理可滚动和不可滚动状态。
- 保持原有 12×15 / 7×15 尺寸、滚轮、拖动、翻页和点击范围；按独立小贴图的实际尺寸取图，避免旧 256×256 图集坐标造成错误。
- 覆盖 AE2 及复用其 DEFAULT / SMALL 滚动条的附属界面。附属自定义样式及其他 Minecraft 界面保持原样；停用配套资源包或缺失贴图时恢复原绘制。

## Installation and scope / 安装与范围

Replace the companion JAR with v1.2.5 and keep resource pack v1.2.4 enabled. No resource pack update is required: its four scrollbar sprites were already present but unused by the old renderer. Restart after replacing the JAR.

将适配模组 JAR 替换为 v1.2.5，继续启用资源包 v1.2.4 即可。无需更新资源包：四张滚动条贴图此前已存在，只是旧绘制器未引用。替换 JAR 后重启。

Compilation and static source/resource inspection do not replace in-game visual acceptance. The game has not been launched and the instance has not been modified.

编译与静态代码/资源核对不能代替游戏内画面验收。本次未启动游戏，未修改游戏实例。
