# v1.2.0

## Installation / 安装

Update both **AE2 Light UI Compat** and **AE2 & Addons Texture Backport** to **1.2.0**. Put the JAR in `mods`, put the ZIP in `resourcepacks` and enable it, remove older copies and restart the client. Minecraft 1.20.1 / Forge only.

请将适配模组和资源包同时更新至 **1.2.0**：JAR 放入 `mods`，ZIP 放入 `resourcepacks` 并启用，移除旧版本后重启客户端。适用于 Minecraft 1.20.1 / Forge。

## Changes / 更新内容

### 中文

请同时更新适配模组与资源包至 1.2.0，并移除旧版本。

- 修复无线终端合成状态页右上角返回按钮的边框类型；统一取消全部、取消按钮的底边和高度，限制 CPU 列表点击范围，避免底部区域命中不可见的 CPU。
- 修复应用机械五种便携化学品存储元件的默认屏幕颜色。1.20.1 的默认染色值为黑色，高版本为浅蓝色 `#80CAFF`。仅修正未手动染色的屏幕图层，保留用户染色和电量指示灯。
- 按 AdvancedAE 1.6.12 恢复量子合成单元紫色边框、量子结构玻璃、量子装备分层模型与材质，以及 IO 总线相关资源。
- 配套适配高级样板编码器的三行布局、方向选中状态，量子装备配置间距和量子合成终端底部高度；高版本状态图标采用独立图集，避免旧版图标坐标错位。

目标版本：Minecraft 1.20.1、Forge 47.4.0、AE2 15.4.11；本次附属核对使用 AdvancedAE 1.3.6、Applied Mekanistics 1.4.3、ExpandedAE 1.4.3。参照 AdvancedAE 1.6.12、Applied Mekanistics 1.6.3 与 AE2 1.21.1。附属适配为客户端视觉修改，不新增高版本迷彩卡等功能。

已通过构建、开发与正式运行映射下 15 个目标类的离线 Mixin 注入及字节码检查。资源另行执行逐文件哈希、PNG、JSON、布局与 ZIP 一致性检查。尚未完成系统性的游戏内视觉验收；离线通过不等于已验证所有分辨率、GUI 缩放及附属组合。

### English

Update both the companion mod and resource pack to 1.2.0 and remove older copies.

- Fix the return-tab frame on wireless crafting status screens. Align Cancel All and Cancel, and prevent invisible CPU rows from intercepting footer clicks.
- Restore the modern default screen tint (`#80CAFF`) for all five Applied Mekanistics portable chemical cells. Explicit dyes and power indicators remain intact.
- Restore AdvancedAE 1.6.12 quantum unit borders, quantum structure glass, layered armor models/textures and IO bus resources.
- Adapt the advanced pattern encoder's three-row layout and selected direction buttons, armor configuration spacing and quantum crafting terminal footer. Use a separate modern icon atlas to preserve legacy coordinates.

Checked against Forge 47.4.0 / AE2 15.4.11, AdvancedAE 1.3.6, Applied Mekanistics 1.4.3 and ExpandedAE 1.4.3. References: AE2 1.21.1, AdvancedAE 1.6.12 and Applied Mekanistics 1.6.3. This is a client-side visual backport; new registered content such as camouflage cards is outside its scope.

Build and offline Mixin/bytecode checks passed for 15 targets under development and production mappings. Resource validation covers hashes, PNGs, JSON, layout bounds and ZIP contents. In-game visual acceptance has not been performed.
