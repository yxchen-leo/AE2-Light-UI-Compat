# v1.2.3

## Changes / 更新内容

- Restore the overloaded pattern provider main GUI from AE2LT 1.21.1 2.1.2-beta3 for the installed 1.20.1 2.1.2-beta2. The missing overloaded_pattern_provider.json override left the old ae2lt:textures/guis/overloaded_pattern_provider.png and legacy player inventory active. Use the modern layout and original 176x245 background region.
- Store that background under a dedicated companion path: the pack already supplies a DIFFERENT ex_pattern_provider.png for ExtendedAE's 243-high screen. Reusing that path would introduce a texture/layout mismatch or change another mod's GUI.
- Apply existing modern 18x20 button rendering to the three TextureToggleButton settings on OverloadedPatternProviderAdvancedScreen. These are registered directly with widgets.add and previously escaped the toolbar marker. Match the exact screen and widget classes and require the dedicated resource. Preserve clicks, settings packets, visibility and tooltips.
- Pigmee provider layout and texture, advanced provider JSON, and 14 relevant mode/return/strategy/speed/filter/frequency icon textures match between the two inspected versions; no replacement needed. Main screen pagination remains 36 slots per page, page label y=33 and duplicated page slot alignment are retained.

- 补上此前缺失的 overloaded_pattern_provider.json 覆盖。低版本原本引用独立旧背景与 legacy 玩家物品栏，替换其他供应器贴图无法影响该页面；现采用高版本布局与 176x245 背景区域。
- 使用专用背景路径，避免与资源包中 ExtendedAE 的 243 高界面及同名 ex_pattern_provider.png 冲突。
- 高级设置页的三个 TextureToggleButton 通过 widgets.add 注册，未被左侧工具栏标记，故此前没有适配。此次限定到该页面与控件类，复用高版本 18x20 背景、悬停和图标位移，并以专用资源存在为启用条件。
- Pigmee 供应器的布局/贴图、高级设置页 JSON、14 张相关状态图标在对比版本中一致。保留分页（每页 36 格）、页码位置、槽位映射、回调及网络操作。
- 此问题来自 GUI 资源覆盖与绘制范围遗漏，与此前 JEI 旧类兼容警告无直接关系。

## Installation and scope / 安装与范围

Replace both JAR and ZIP. Compilation and static source/resource comparison are not runtime or visual acceptance. No game launched and no instance/save modified. Existing v1.2.1/v1.2.2 fixes retained.

配套替换 JAR 与 ZIP。仅编译与静态代码/资源对比，未进行游戏内画面验收，未启动游戏或修改实例和存档。保留之前的修复。参考版本为本地保存的高版本 beta3，并非对所有新版闪电科技作兼容保证。

Install the JAR in `mods`, enable the ZIP in `resourcepacks`, remove older copies and restart. The existing optional mekmm loot fix requires the JAR on dedicated servers.

JAR 放入 `mods`，ZIP 放入 `resourcepacks` 并启用，移除旧版本后重启。已有的 mekmm 战利品修复在独立服务器上仍需安装 JAR。

README pages now have separate English and Chinese text with clickable language links. Version banners use the page language; Chinese titles use the Chinese project name.

README 现提供独立中英文页面和可点击的语言链接，版本提示使用对应语言，中文标题仅使用中文项目名称。
