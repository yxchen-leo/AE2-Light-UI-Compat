# v1.2.4

## Changes / 更新内容

### 中文

- 配套移植 AE2 19.2.18 的设置开关贴图、状态与文字布局，修复取消勾选后焦点导致的持续高亮。
- 鼠标点击仅在开关图形内生效；右侧文字不再触发选项。原有选项保存逻辑保持不变。
- 继续包含 v1.2.3 的闪电科技过载样板供应器布局与独立背景修复；请同时更新适配模组与资源包，并启用新资源包。
- 适配模组使用与资源包相同的图标。


### English

- Port AE2 19.2.18 settings toggle sprites, states and label layout; prevent retained focus from keeping an unchecked toggle highlighted.
- Limit mouse interaction to the toggle graphic; clicking the label no longer changes the option. Existing option persistence is preserved.
- Retain v1.2.3 Lightning Tech overloaded pattern provider layout and isolated background fixes. Update both the companion and resource pack, then enable the new pack.
- Use the resource pack icon for the companion mod.


## Installation and scope / 安装与范围

Install the v1.2.4 JAR in `mods`, enable the matching ZIP in `resourcepacks`, remove the previous JAR and disable older packs, then restart. Both components are required for the new toggle style. The existing optional mekmm loot fix requires the JAR on dedicated servers.

将 v1.2.4 JAR 放入 `mods`，在 `resourcepacks` 启用配套 ZIP，移除旧 JAR、停用旧资源包后重启。新的开关样式需要两者配套使用。已有的 mekmm 战利品修复在独立服务器上仍需安装 JAR。

Compilation and packaging checks passed. In-game visual verification has not been performed. Mouse interaction limited to the icon is a deliberate adjustment requested for this backport.

已通过编译与打包检查，未进行游戏内画面验收。仅允许点击开关图形是本次移植按用户要求作出的交互调整。
