# v1.2.2

## Changes / 更新内容

- Restore AdvancedAE output-face buttons to the modern AE2AddonLib renderer: 18x20 backgrounds, original enabled/disabled atlas regions and row positions y=6/28/50. Keep item icons, tooltips, side selection and server actions. Removing the dedicated atlas restores legacy drawing/layout.
- Correct ExpandedAE 1.4.3's own English/Chinese energy-cell guide recipe ID from exp_exp_energy_cell to expandedae:exp_energy_cell. Fix the missing space after the Chinese heading marker. Only these two version-matched guide pages are overridden.

- 反应仓面配置按钮使用高版本 18x20 背景、启用/禁用图块与 6/28/50 三行纵坐标，保留相邻方块图标、提示、面选择及服务端操作。缺少专用图集时恢复旧版绘制与布局。
- 修正 ExpandedAE 1.4.3 自带中英文能源元件手册中的 exp_exp_energy_cell 拼写错误，改为 expandedae:exp_energy_cell，并修正中文标题缺少空格的问题。仅覆盖这两张与已安装版本匹配的页面。

## Installation / 安装

Update both the companion JAR in `mods` and the ZIP in `resourcepacks` to 1.2.2, remove older copies, enable the resource pack and restart Minecraft 1.20.1 / Forge. The guide-only fix works through the resource pack; modern output-face buttons require both artifacts. The existing optional mekmm loot fix still requires the JAR on dedicated servers.

请将 `mods` 中的适配 JAR 与 `resourcepacks` 中的 ZIP 配套更新至 1.2.2，移除旧版本、启用资源包并重启 Minecraft 1.20.1 / Forge。手册修复单独通过资源包生效；面配置按钮需要配套 JAR。已有的 mekmm 战利品修复在独立服务器上仍需安装 JAR。
