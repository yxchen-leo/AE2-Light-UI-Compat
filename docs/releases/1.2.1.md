# v1.2.1

## Installation / 安装

Update both **AE2 Light UI Compat** and **AE2 & Addons Texture Backport** to **1.2.1**. Replace the old JAR in `mods`, replace and enable the ZIP in `resourcepacks`, disable older overlapping packs and restart Minecraft 1.20.1 / Forge.

请将适配模组与资源包同时更新为 **1.2.1**，替换 `mods` 中的旧 JAR、替换并启用 `resourcepacks` 中的 ZIP，停用旧版重叠资源包并重启 Minecraft 1.20.1 / Forge。

**Loot fix:** single-player uses the normal client installation. For multiplayer, install this companion JAR on the dedicated server too; the client resource pack cannot repair server loot data. GUI rendering remains client-side.

**战利品修复：**单人游戏安装客户端 JAR 即可；多人游戏需要独立服务器也安装配套 JAR。客户端资源包不能单独修复服务器战利品数据，GUI 渲染仍仅在客户端运行。

## Changes / 更新内容

- Remove 603 imported GuideME files across 12 namespaces. Installed mods now provide their own guides, avoiding high-version-only item references, missing navigation icons and pack-induced index conflicts.
- Remove four ae2additions formed storage model overrides that reference unavailable custom loaders: 1024k, 4096k, 16384k and 65536k. Retain the remaining textures and model assets.
- Add a common-side compatibility hook for 70 optional factory loot tables shipped in mekmm 1.1.2. Skip a table ONLY if its original JSON fingerprint matches and its corresponding block AND item are absent. Registered machines, original inventory/energy/security NBT and modified datapack tables pass through unchanged.
- Preserve v1.2.0 GUI and texture fixes. No shader, recipe, JEI/EMI or world-save changes are included.

- 移除涉及 12 个命名空间的 603 个高版本 GuideME 文件，恢复使用已安装模组自身的手册，消除资源包引入的未知物品引用、导航图标缺失与索引冲突。
- 移除 ae2additions 的四个成型存储模型覆盖：1024k、4096k、16384k、65536k；它们引用当前未注册的自定义加载器。其余材质与模型资源保留。
- 配套 JAR 为 mekmm 1.1.2 的 70 张可选工厂战利品表加入两端兼容钩子。只有表内容指纹匹配原件、且对应方块与物品均不存在时才跳过；已注册机器的原始掉落、物品栏/能量/权限 NBT 和用户修改的数据包表均保持原逻辑。
- 保留 v1.2.0 的 GUI 与材质修复。本版本不包含着色器、配方、JEI/EMI 或存档修改。

## Findings / 原因说明

The mekmm errors concern unavailable optional factory tiers, not confirmed broken drops from existing machines. Five optional tiers each ship 14 factory tables while factory registration follows runtime-available tiers. This fix does not invent replacement drops or register new machines.

mekmm 报错对应未注册的可选工厂等级，不能直接推定现有机器拆除后会丢失掉落。五个可选等级各附带 14 张表，而机器注册跟随运行时可用等级。此次修复不添加新机器或伪造替代掉落。

## Validation / 核对范围

Compiled and reobfuscated against Forge 47.4.0. Inspected the hook signature in Forge 47.4.10 and 47.4.20. Checked resource provenance, PNG/JSON integrity, ZIP/tree identity and release artifact metadata. All retained visual asset bytes match v1.2.0; the only modified retained pack file is CREDITS.txt. **No game launch, runtime Mixin test, dedicated-server playthrough or in-game drop test was performed for this release.**

已完成 Forge 47.4.0 编译与重混淆，并静态核对 47.4.10、47.4.20 的钩子签名；核对逐文件来源哈希、PNG/JSON、ZIP 与源码目录一致性及附件元数据。保留的视觉资源与 v1.2.0 字节一致，保留文件中仅 CREDITS.txt 更新。**本次未启动游戏，未执行运行时 Mixin、独立服务器或实机掉落测试。**

See `docs/1.2.1-compatibility.md` for details. / 详细原因与处理边界见 `docs/1.2.1-compatibility.md`。
