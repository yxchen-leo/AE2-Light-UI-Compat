## Installation / 安装

Minecraft **1.20.1 / Forge 47.x / AE2 15.x**, with AE2's required dependencies. Remove older companion JARs, install the attached JAR in the client's `mods` folder, and restart the client. No server installation is required.

Use **AE2 & Addons Texture Backport 1.1.2** alongside this mod. Update both the JAR and the resource-pack ZIP; the resource pack is distributed separately.

适用于 Minecraft **1.20.1 / Forge 47.x / AE2 15.x**，需安装 AE2 的必要依赖。移除旧版适配模组 JAR，将附件放入客户端 `mods` 文件夹并重启客户端；服务端无需安装。

请搭配 **AE2 & Addons Texture Backport 1.1.2**，同时更新 JAR 与资源包 ZIP。资源包单独提供，启用新包前请停用旧版。

## Changes / 更新内容

- Fixes back arrows on the ME Drive priority page, wireless terminal trash/settings pages, and compatible addon submenus. Original callbacks and tooltips are retained.
- Adds the modern priority icon, tab backgrounds, focus states and icon offsets. Ordinary item/mode tabs keep their own icons. The dedicated `tab_buttons.png` enables the feature; removing it restores legacy rendering.
- Matches the modern opacity behavior for full-size toolbar icons and corrects outdated text-color documentation.
- Adds a detailed GUI implementation audit, verified addon call paths and documented differences that remain.

- 修复 ME 驱动器优先级、无线终端垃圾桶/设置及兼容附属子页面的返回箭头，保留原有点击行为和提示文字。
- 适配高版本优先级入口图标、页签背景、焦点状态与图标偏移。普通物品/模式页签保留自己的图标；专用 `tab_buttons.png` 存在时启用，移除后恢复旧版渲染。
- 对齐完整尺寸工具栏图标的透明度行为，修正旧文档中的文字配色说明。
- 增加 GUI 实现核对报告、已核实的附属调用路径和剩余差异说明。

## Verification and scope / 验证与范围

Gradle build and real Mixin transformations with ASM checks passed for **8 target classes**, under both development and production Forge 47.4.0 / AE2 15.4.11 mappings. The matching pack and release artifacts were checked. **No in-game visual verification was performed.**

This remains a partial visual backport. Checkbox geometry, scrollbar APIs, slot highlights, quantity shortcuts and custom addon renderers retain documented differences. See the [GUI audit](https://github.com/yxchen-leo/AE2-Light-UI-Compat/blob/v1.1.2/docs/1.1.2-GUI-audit.md).

已通过 Gradle 构建及开发、正式运行映射下 **8 个目标类**的真实 Mixin 转换和 ASM 检查，基准为 Forge 47.4.0 / AE2 15.4.11；已核对配套资源包及发布附件。**尚未进行游戏内画面验收。**

当前仍是部分外观移植。复选框、滚动条接口、槽位高亮、数量快捷操作及附属自绘控件仍有已记录差异，详见上述 GUI 核对报告。
