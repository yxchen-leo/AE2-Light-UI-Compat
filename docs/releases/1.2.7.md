# v1.2.7

## Changes / 更新内容

- Set the companion mod author to `cyx`.
- Display the matching resource pack as **AE2 & Addons Texture Backport**, independently of its ZIP/folder filename. Read the custom metadata during pack discovery; keep the underlying pack ID and selection behavior unchanged.
- Show **Minecraft 1.20.1 | v1.2.7** in the description. Apply the title only to file-based client resource packs carrying the matching identifier; other packs and server data packs retain their titles.

- 将适配模组作者改为 `cyx`。
- 配套资源包在游戏列表中固定显示为 **AE2 & Addons Texture Backport**，不再以 ZIP/文件夹名作为显示标题。扫描资源包时读取名称标识，内部 ID 与选择逻辑保持不变。
- 说明行显示 **Minecraft 1.20.1 | v1.2.7**。仅识别携带指定标识的客户端文件资源包，其他资源包和服务端数据包标题保持原样。

## Installation and scope / 安装与范围

Use companion and resource pack **v1.2.7** together. Without this companion, Minecraft 1.20.1 uses the filename as the pack title. Replace the old JAR, enable the new ZIP and restart. Compilation and packaging checks passed; in-game visual acceptance has not been performed.

请配套使用模组和资源包 **v1.2.7**。未安装新版适配模组时，Minecraft 1.20.1 仍使用文件名作为资源包标题。替换旧 JAR、启用新 ZIP 后重启。编译与打包检查通过，未进行游戏内画面验收。
