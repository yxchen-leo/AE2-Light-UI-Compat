# v1.2.8

## Changes / 更新内容

- Simplify shared theme-resource lookup, toolbar eligibility and repeated AdvancedAE scrollbar setup; standardize Java formatting and imports while preserving GUI coordinates, callbacks and resource-reload fallback.
- 整理主题资源读取、工具栏适配条件和 AdvancedAE 重复滚动条逻辑；统一 Java 格式及导入，保留 GUI 坐标、回调与资源重载回退。
- Expand offline verification from 10 to 15 required targets, including checkboxes, scrollbars, slot highlights, pack display names and the guarded loot hook; retain five optional AdvancedAE checks.
- 必测目标由 10 个增至 15 个，补齐复选框、滚动条、槽位高亮、资源包显示名称和战利品钩子；保留 5 个 AdvancedAE 可选目标检查。
- Remove unused dependency templates and duplicate ignore rules; document the source layout and formatting conventions. Author remains `cyx`.
- 删除未使用的依赖模板和重复忽略规则，补充源码结构与格式约定；作者仍为 `cyx`。

## Installation / 安装

Minecraft **1.20.1 / Forge 47.x / AE2 15.x**. Replace the previous companion JAR and enable [AE2 & Addons Texture Backport v1.2.8](https://github.com/yxchen-leo/AE2-Addons-Texture-Backport/releases/tag/v1.2.8). Restart Minecraft. GUI features run on the client; the optional mekmm loot fix requires the JAR on a dedicated server as well.

替换旧版适配 JAR，启用配套资源包并彻底重启游戏。GUI 功能安装在客户端；独立服务器如需可选 mekmm 战利品修复，也需安装本 JAR。不新增游戏物品或方块。

## Validation / 验证

已完成构建与重混淆；提供 AdvancedAE 1.3.6 后，**20 个配置目标**通过真实 Mixin 转换和 ASM 检查，并核对 JAR 元数据、Mixin 类及引用映射。未启动游戏、未做画面或独立服务器验收，不代表所有附属及版本均已验证。
