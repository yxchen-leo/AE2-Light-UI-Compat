## Installation / 安装

Minecraft **1.20.1 / Forge 47.x / AE2 15.x**, with AE2's required dependencies. Remove older companion JARs, install the attached JAR in the client's `mods` folder, and restart the client. No server installation is required.

Use **AE2 & Addons Texture Backport 1.1.3** alongside this mod. Update both the JAR and the resource-pack ZIP; the resource pack is distributed separately.

适用于 Minecraft **1.20.1 / Forge 47.x / AE2 15.x**，需安装 AE2 的必要依赖。移除旧版适配模组 JAR，将附件放入客户端 `mods` 文件夹并重启客户端；服务端无需安装。

请搭配 **AE2 & Addons Texture Backport 1.1.3**，同时更新 JAR 与资源包 ZIP。资源包单独提供，启用新包前请停用旧版。

## Changes / 更新内容

- Changes the in-game mod display name to **AE2 Light UI Compat**, removing the Chinese name and parentheses.
- Pairs with resource pack 1.1.3, which removes four invalid resource files and uses an English display description.

- 游戏内模组显示名改为 **AE2 Light UI Compat**，移除中文名称和括号。
- 搭配资源包 1.1.3：删除四个非法资源文件，并采用英文显示说明。
