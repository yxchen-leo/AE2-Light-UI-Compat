# v1.2.6

## Changes / 更新内容

- Restore the ExtendedAE wireless extended crafting terminal item appearance with the existing modern wireless crafting sprite; add its model and seven missing Simplified Chinese translations. The inspected newer ExtendedAE has no same-named item, so this is a style adaptation.
- Port AE2 slot hover borders/fill and disabled optional-slot opacity while retaining legacy slot bounds and input behavior.
- Restore the modern right toolbox with an isolated atlas. Correct compatible Lightning Tech machine inventory, energy-bar, output-clear-button, frame and title details; correct Crystal Science simple-provider inventory and ExpandedAE IO-port frame height.
- Pair the Lightning Tech modern crafting report texture/layout with matching footer height and source slices in the companion.

- 补上 ExtendedAE 无线扩展合成终端的物品模型与现代风格贴图，以及 7 条缺失中文翻译。所核对高版本没有同名物品，图标为复用现有无线合成终端素材的风格适配。
- 移植槽位悬停边框/填充及禁用可选槽位透明度，保留原槽位范围与交互。
- 补齐右侧工具箱独立图集/布局；修正闪电科技部分机器的物品栏、能量条、输出页清除按钮、背景裁切和标题位置；修正水晶科技简易供应器物品栏与 ExpandedAE IO 端口背景高度。
- 配套移植闪电科技合成确认背景和页脚裁切代码。

## Installation and scope / 安装与范围

Use both companion v1.2.6 and resource pack v1.2.6. Replace the older JAR, enable the new ZIP, disable older packs and restart. New menu features and guide pages are not included. Compilation and static inspection do not replace in-game visual acceptance.

请配套使用适配模组 v1.2.6 和资源包 v1.2.6，替换旧 JAR、启用新 ZIP 并停用旧资源包后重启。未引入新版菜单功能或手册页面。编译和静态核对不能代替游戏内画面验收。
