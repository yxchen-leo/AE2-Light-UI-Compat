# 1.1.2 GUI 实现核对与返回按钮修复

核对日期：2026-10-18。目标为 Minecraft 1.20.1 / Forge，参照 AE2 1.21.1。**本模组仍是客户端外观适配层，不是高版本 AE2 GUI 框架、菜单与网络协议的完整移植。**

## 参照与验证范围

- 低版本基准来自用户实际使用的 PrismLauncher 1.20.1 实例。
- 实际安装 AE2 15.4.11、AE2WTLib 15.3.3、AdvancedAE 1.3.6、ExtendedAE 1.4.21、MEGA Cells 2.4.6、水晶科技 1.2.0、闪电科技 2.1.2-beta2、ME Requester 1.2.1、Applied Mekanistics 1.4.3、ae2CraftingTree 1.1.1。
- AE2 源码：1.20.1 提交 `1c2f96e70ca6b61e8120482923e9775d772fd9e7`，1.21.1 提交 `db17504a86128fdf3dae31f5fb7a112a646e0b93`。
- 附属关键 GUI 类从实际安装 JAR 与官方 1.21.1 JAR 反编译比较。高版本参照包含 AE2WTLib 19.5.1、水晶科技 1.2.1、闪电科技 2.1.2-beta3、AdvancedAE 1.6.12、ExtendedAE 2.2.33、MEGA Cells 4.11.0、ME Requester 1.5.0。
- 全部资源文件核对、来源哈希及附属资源支持表见配套资源包的 `docs/1.1.2-完整核对.md` 和 `audit/1.1.2/`。资源命名空间数不等于模组数：许多附属把屏幕布局放在 `assets/ae2/screens/`。

## 返回图标问题的根因

高版本不是把物品材质重画成箭头。它在创建返回按钮时，将 `TabButton(ItemStack, ...)` 改为 `TabButton(Icon.BACK, ...)`。1.20.1 没有 `Icon.BACK` 枚举值，当前资源包也无法改变 Java 构造参数；所以此前即使背景和左侧工具栏已变成高版本样式，右上角仍显示宿主物品。

| 页面/入口 | 1.20.1 创建路径 | 1.21.1 差异 | 1.1.2 处理 |
| --- | --- | --- | --- |
| ME 驱动器的优先级页 | `PriorityScreen` → `implementations.AESubScreen.addBackButton` | 宿主物品变为 `Icon.BACK` | 公共辅助方法标记为返回按钮 |
| 无线终端垃圾桶 | AE2WTLib `TrashScreen` → 同一公共方法 | 由高版本公共方法生成箭头 | 同时修复代码与资源布局 |
| 无线终端设置 | AE2WTLib `WirelessTerminalSettingsScreen` 直接构造 `TabButton` 并注册为 `back` | 直接使用 `Icon.BACK` | 注册阶段识别 `back` |
| AE2 终端设置 | `TerminalSettingsScreen.addBackButton` | 直接使用 `Icon.BACK` | 注册阶段识别 `back` |
| 样板处理数量设置 | `SetProcessingPatternAmountScreen` | 直接使用 `Icon.BACK` | 注册阶段识别 `back` |
| 合成数量、库存数量、合成状态 | 公共 `AESubScreen.addBackButton` | 同上 | 公共辅助方法覆盖 |
| AdvancedAE 输出方向/部分量子盔甲设置 | 调用公共辅助方法 | 使用高版本公共返回路径 | 自动覆盖调用路径 |
| ae2CraftingTree 的树形页和设置页 | 自建 `TabButton`，注册为 `back` | 高低版本依赖的 AE2 图标实现不同 | 注册阶段覆盖；不等于整个树形界面已移植 |

修复保存按钮原有的物品字段、提示文字、点击处理和菜单返回协议，仅在渲染阶段选择箭头。普通物品页签，例如样板编码模式，不会因为其内容是 `ItemStack` 就被替换成箭头。

## 本轮代码和资源变化

- `NavigationTab` 记录按钮用途；`WidgetContainer.add` 识别 `back`、`button_back`、`openPriority` 和 `craftingStatus`。公共 `AESubScreen.addBackButton` 额外标记返回语义，覆盖附属自定义 ID 的调用。
- `TabButtonMixin` 与 `TabRenderer` 使用高版本页签背景尺寸、焦点状态和图标位置。方框普通背景为 20×20，横向页签为 22×22；图标按样式使用 1/2/3 像素边距，再上移 1 像素。保留旧版实际点击区域和回调。
- 返回图标读取高版本图集的 `(96,16)`，优先级入口读取 `(144,64)`。终端合成状态按钮按高版本使用方框背景。其余图标继续从旧版图集读取，避免跨版本坐标错配。
- 新增 `assets/ae2lightuicompat/textures/gui/tab_buttons.png`，为上游 `states.png` 原字节副本；不覆盖旧版图标图集。专用图集缺失时恢复原始页签渲染和物品图标，资源重载后重新判断。
- 配套资源包把无线垃圾桶的返回按钮由 `(150,-4,hideEdge)` 改为 `(152,-5,20,20)`；为无线设置页新增布局覆盖，将返回按钮由 `(179,0)` 改为 `(176,-5)`。磁铁设置页已经是高版本定位，本次没有修改。
- 普通完整尺寸侧栏图标在禁用时保持高版本的不透明绘制；此前适配层额外使用了 0.5 透明度。半尺寸控件继续走原有渲染。
- 修正文档中仍描述 1.0.x 深色文字的段落，说明完整主题与旧版仅提供 `widgets.png` 的主题具有不同配色。

## 仍然存在的 GUI 底层差异

| 层次 | 高版本实现 | 当前适配与边界 |
| --- | --- | --- |
| 文字按钮 | `AE2Button` + GUI sprite + 自定义无阴影文字 | 在 1.20.1 `AbstractButton` 中按 AE2 注册范围换图和渲染文字；颜色、垂直偏移、长文本滚动已适配，但渲染类、背景九宫格 API 和焦点选择仍不是同一实现 |
| 左侧工具栏 | `VerticalButtonBar` 直接使用 sprite 九宫格；间距 6 | 手动分段绘制底板，包裹完整按钮虚方法调用；完整 16×16 控件适配。独立创建、非标准尺寸、半尺寸控件和附属自绘背景不能一概视作完整支持 |
| 页签 | 新图标、背景尺寸/偏移；新增禁用背景选项 | 本轮适配返回/优先级图标与常见页签渲染；旧 API 没有完整复制高版本 `disableBackground` 接口；子类完全自行绘制且不调用父渲染时仍可绕过适配 |
| 复选框/单选框 | 普通开关为 22×12 区域；文字缩进和悬停/焦点逻辑变化 | 仍使用 1.20.1 `AECheckbox` 的 14×14 渲染逻辑，资源包样式不能替代这项代码差异 |
| 滚动条 | sprite 资源与新增 `BIG` 样式 | 旧版按图集区域和旧样式绘制；新增尺寸/布局不是单靠贴图覆盖就能完全对应 |
| 数量输入 | 支持 Shift/Ctrl 切换 1/16/32/64 步长；增加按钮文字状态与计算规则 | 仍保留 1.20.1 数量输入功能；只适配外观，没有把高版本的新交互功能加入旧菜单 |
| 槽位高亮 | 蓝色填充和边框；禁用槽位覆盖透明度变化 | 保留旧版槽位高亮和菜单状态逻辑；未移植新高亮绘制 |
| 基础屏幕/帮助 | 工具栏可选创建、GuideME 接口变化、NeoForge 数据包接口 | 保留 Forge/AE2 15.x 客户端菜单与网络协议，不引入高版本接口 |
| 附属自有 GUI | 各附属有额外按钮、页签、屏幕和自绘逻辑 | 已核实下表中的继承和调用路径；未声称所有附属、所有屏幕都运行验收通过 |

上述剩余差异是实际实现范围，不应将 1.1.2 描述为高版本 GUI 的完整复制。

## 用户实例内附属的代码支持

| 附属 | 核实的实现路径 | 当前支持 |
| --- | --- | --- |
| AE2WTLib 无线终端 | `TrashScreen`、`WirelessTerminalSettingsScreen`、`MagnetScreen` | 返回箭头和页签适配；垃圾桶/设置页定位修正；独立磁铁控件仍受通用适配范围限制 |
| AE2 Crystal Science 水晶科技 | `AECSIconButton` 直接继承 Minecraft `Button`，而非 AE2 `IconButton` | 已注册工具栏的完整尺寸控件由共同标记/渲染作用域适配，自定义图标保留；其他独立控件不保证覆盖 |
| AE2 Lightning Tech 闪电科技 | `TextureToggleButton` 在父渲染后继续绘图；附属 `AE2Button` 在旧版继承普通 `Button` | 工具栏作用域保留附加图标；AE2 注册的普通文字按钮可适配；自绘页签、部分独立控件及新版本新增屏幕不能推定完全一致 |
| AdvancedAE | `AdvPatternProviderScreen`、`AdvancedIOBusScreen` 等注册工具栏；若干设置页调用公共返回方法 | 支持这些通用路径；量子盔甲等复杂自绘页面不等于整体移植 |
| ExtendedAE | `EPPButton` 继承 `IconButton`；`GuiExDrive`、`GuiExInterface` 等使用 AE2 体系 | 通用按钮/页签可适配；装配矩阵等自绘逻辑仍保留旧版 |
| MEGA Cells | `CellDockScreen` 继承 `AEBaseScreen` | 通用控件可适配；资源移植和世界渲染另行核对 |
| ME Requester | `AbstractRequesterScreen` 继承 `AEBaseScreen`，终端注册左侧按钮 | 通用注册路径可适配；自定义请求列表与布局仍是旧实现 |
| Applied Mekanistics | 实际 JAR 未发现独立客户端 GUI 类 | 主要借用 AE2 基础界面；不能据此宣称全部新版本特性已移植 |
| ae2CraftingTree | `CraftingTreeScreen` / `SettingScreen` 继承 `AESubScreen`，注册返回页签 | 返回按钮受益；当前资源包没有 `ae2ct` 专属资源覆盖，树形绘制仍是旧版 |

## 验证和安装

Gradle 构建通过；开发映射和 Forge 正式运行映射分别执行真实 Mixin 转换与 ASM 检查，覆盖 8 个目标类。检查保留原始页签物品/图标字段、返回标记、非返回页签的分类，以及附属覆盖方法所需的虚调用。资源包 JSON/PNG、源图集哈希和 ZIP 内容核对通过。

**未启动 Minecraft 进行画面验收，也未把 JAR 安装到用户实例。** 离线检查不能证明所有附属 Mixin 的组合和每个页面都没有运行问题。

同时替换 `AE2-Light-UI-Compat-Forge-1.20.1-1.1.2.jar` 和 `AE2-Addons-Texture-Backport-1.20.1-v1.1.2.zip`，移除旧适配 JAR、停用旧资源包后重启。优先检查 ME 驱动器优先级、无线垃圾桶/设置、磁铁设置、样板模式页签、合成状态入口、按钮焦点和资源包重载。下载见 [1.1.2 Release](https://github.com/yxchen-leo/AE2-Light-UI-Compat/releases/tag/v1.1.2)。
