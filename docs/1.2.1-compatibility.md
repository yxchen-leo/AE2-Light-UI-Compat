# v1.2.1 compatibility / 兼容核对

## 中文

- GuideME：v1.2.0 导入了 603 个跨版本手册文件（含图片），涉及 12 个命名空间。当前日志有 115 组未知物品与页面的关联、28 个相关页面；图标错误还明确标注来源为 v1.2.0 ZIP。移除该资源包的全部 ae2guide 覆盖，让已安装模组自己的手册生效；原模组同路径页面中未发现这些相同的未知物品引用。这样也移除了资源包引入的 ae2cs 索引冲突。不伪造不存在的物品，也不屏蔽 GuideME 日志。
- 模型：四个 ae2additions `1024k/4096k/16384k/65536k_storage_formed.json` 仅声明自定义 loader；当前安装的模组未提供 ae2additions 资源与对应加载器。这些是资源包遗留覆盖，不能由报错直接推定当前有四种已注册方块损坏。移除四个覆盖；保留其余贴图与模型。将来安装附属时由附属自己的模型定义生效。
- 战利品：mekmm 1.1.2 的工厂注册循环使用运行时 `EnumUtils.FACTORY_TIERS`，而 JAR 附带了更多工厂等级的数据。当前报错的 70 张表均属于 creative、dense、multiversal、overclocked、quantum 五个可选等级，每级 14 张。报错 ID 与表的自身掉落 ID 一致。这是未注册可选机器的残留数据，并非已确认存在的机器无法掉落。
- 配套 JAR 在 Forge 战利品反序列化之前处理上述表。条件必须同时满足：loot_tables 类型、精确表 ID、表 JSON 的 SHA-256 与原件匹配、相同 ID 的方块和物品都不存在。任何一个条件不满足均走原始加载。实际存在的机器及其原始掉落/NBT、用户数据包替换、其他模组和新版本修改过的表不受处理。
- 服务端：GUI Mixin 仍仅在客户端加载；新增战利品 Mixin 在两端可用。单人游戏使用客户端安装即可；独立服务器必须也安装此 JAR 才能处理其战利品加载。资源包 ZIP 无法单独修复服务器数据。

## English

The pack removes 603 imported GuideME files across 12 namespaces, deferring to installed mod guides, and four ae2additions formed-model overrides with unavailable custom loaders. The remaining visual assets are retained.

mekmm 1.1.2 registers factories from the available runtime tiers but ships loot data for additional tiers. The 70 reported failures cover 14 factories in each of five optional tiers. The common-side hook skips only an exact original table fingerprint whose matching item AND block are both absent. Registered factories, their original loot/NBT, user datapack replacements and changed upstream tables pass through untouched. No machines or replacement drops are invented.

Install the companion JAR on a dedicated server to enable the loot fix there. GUI mixins remain client-only; single-player needs only the normal client installation.
